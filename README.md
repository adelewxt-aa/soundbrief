# SoundBrief

面向短视频创作者的 AI 配乐助手原型：从视频的内容、情绪和预算出发，帮助用户规划配乐、比较不同方向，再继续调整。

## 为什么做这个项目

创作者知道“这里想更温柔”“产品出现时想更有记忆点”，却不一定懂音乐术语，也不想反复切换平台试模型。SoundBrief 希望把这些具体需求转成配乐计划，并在未来根据需求匹配不同音乐模型，而不是只提供一个生成按钮。

## 目前可以体验什么

- 六只猫咪主题、不同造型，以及对应的六支预制示例短片。
- 上传本地视频，或选择示例，体验六步创作流程。
- 编辑配乐要求、记录时间点，查看模型与创作方向的规划界面。
- 播放成片原声、静音看画面，或导入自己的音乐同步试听。
- 记录局部修改要求；对导入音乐进行基础音量调整，保存配乐计划及部分音频结果。

六步流程：选择视频 → 配乐计划 → 模型与方向 → 试听比较 → 继续修改 → 保存结果。

## 哪些还没有实现

目前是可交互产品原型，尚未接入视频理解或音乐生成 API。

- 示例视频由创作者在外部工具制作，不是本站实时生成。
- 配乐计划需要用户确认；当前没有自动识别剧情或精确卡点。
- 模型推荐、费用估算和局部重新生成仍在规划中，不代表已真实调用或计费。
- 四种配乐方向是创作选项，不是已经生成的四首音乐。

## 重要产品更新

以下按开发记录整理，只保留影响产品定位和核心体验的变化，不代表每次变更均已上线。

### 2026-09-14 — 用六支完整短片串起示例体验

- 将示例更新为六只猫咪主演的短片，对应日常 Vlog、萌宠、产品广告、门店氛围、教程和活动六类配乐场景，保留成片原声。
- 同一支视频贯穿六步工作台，用户可以边看画面边记录配乐时间点，再导入其他音乐比较，不再只看静态说明。
- 明确区分“预制成片”“可编辑计划”和“未来 AI 能力”，避免把示例误当成实时生成结果。

### 2026-09-07 — 从单一结果转向可选择、可修改的配乐方案

- 设计多模型选择界面：围绕视频用途、风格和预算展示选择依据，并预留费用确认环节。自动推荐、真实报价与模型调用尚未接入。
- 增加“刚刚好、氛围感、小惊喜、轻预算”四种创作方向，以及分段保留和自然语言修改需求的交互；目前用于规划与记录，不代表已实现局部重新生成。

### 2026-09-07 — 重做首页与猫咪陪伴体验

- 增加独立首页，先说明产品能帮创作者解决什么，再提供“开始配乐”和“看看例子”两条入口。
- 从一只布偶猫扩展到六只具名猫咪、六套配色和各自四种造型，支持保存外观偏好；统一为温柔、易懂的陪伴式文案。

### 2026-09-04 — 搭建六步创作流程

- 将体验拆成选择视频、配乐计划、模型与方向、试听比较、继续修改、保存结果，让用户知道每一步需要做什么、会得到什么。
- 完善页面跳转、本地视频上传和试听操作，让原型从页面展示走向可操作的创作流程。

### 2026-08-28 — 完成首版交互原型

- 围绕短视频创作者“找音乐耗时、音乐不贴画面”的问题，搭建 SoundBrief 首版，探索从视频需求出发的配乐体验。

最近的界面整理（2026-09-16）：修复示例封面超出卡片、优化文字可读性，补充项目说明。卡片修复已通过本地构建检查，尚未完成本次网站发布。

## 本地运行

使用 Node.js 22.13 或更高版本，以及 pnpm：

```sh
pnpm install --frozen-lockfile
pnpm dev
```

构建：`pnpm build`。当前技术栈为 React、Next.js 组件结构、TypeScript 和 Vinext，发布配置面向 Workers；迁移到其他云平台需要适配，不能直接假设上传即可运行。
