# SoundBrief 创作资料备份

整理日期：2026-09-28。

- original-videos：网站六支猫咪短片的原始 MP4，保留重新剪辑所需版本。
- early-video-drafts：Downloads 中可按名称明确关联布偶/三花角色的三支早期视频。
- exported-projects：已导出的三个项目 JSON 和一份调整后 WAV。JSON 是不同阶段的导出记录，不保证当前界面支持重新导入。

网页实际使用的压缩素材仍在 public/media 中。这些原始资料不需要放进 public，不影响现有网站资源路径。

未纳入仅凭文件名无法确认归属的视频、其他项目的桌面宠物图片、可重新生成的临时渲染和安装缓存。浏览器内未导出的编辑状态与账号登录信息不在 Git 备份中。
